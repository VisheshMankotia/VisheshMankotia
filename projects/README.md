# Project Portfolio

This folder contains research and development projects at the intersection of biotechnology, bioinformatics, cheminformatics and AI.

## Projects

### 1. [TissueTalk](TissueTalk/)
Interactive spatial gene-expression exploration. The Streamlit starter app accepts an AnnData `.h5ad` file, lets the user select a region and compares gene-wise mean expression inside and outside that region.

### 2. [CDK2–Tivozanib Molecular Docking](CDK2-Tivozanib-Molecular-Docking/)
A documented AutoDock learning workflow for exploring a CDK2–Tivozanib protein–ligand docking setup. Includes a parameter-record template and guidance on responsible interpretation.

### 3. [Medicinal Plant Bioprospecting](Medicinal-Plant-Bioprospecting/)
An exploratory cheminformatics workflow for source-linked phytochemical curation, RDKit molecular descriptors and computational prioritization.

## Research integrity
These projects include prototypes, learning workflows and ongoing investigations. A computational prediction is not an experimental result. Dataset provenance, software versions, parameters, limitations and validation status should be documented before reporting conclusions.
