# Literature and compound source log

Use this file to record traceable evidence for each plant and compound. Suggested fields:

| Field | What to record |
|:--|:--|
| Plant | Accepted scientific name and authority, if available |
| Plant part | Leaf, seed, fruit, root, etc. |
| Compound | Reported compound name and identifier |
| Evidence | Isolation, analytical identification, literature report or database record |
| Method | Extraction and analytical method described by the source |
| Source | DOI, PMID, database URL or full citation |
| Confidence | Whether identity was experimentally confirmed and by which method |
| Notes | Limitations, conflicting reports and follow-up needed |

Useful starting points include [PubChem](https://pubchem.ncbi.nlm.nih.gov/), [PubMed](https://pubmed.ncbi.nlm.nih.gov/) and [Google Scholar](https://scholar.google.com/). Verify each record against the primary source before using it.
