# Data directory

Place curated input tables here. Do not commit confidential, restricted, copyrighted, or personally identifiable data.

For the descriptor starter script, create `compounds.csv` with columns:

```csv
compound,smiles
Example compound,CCO
```

The example structure above is only a software smoke-test molecule, not a medicinal-plant compound or an anticancer candidate. Replace it with a source-verified structure and cite its provenance in the project references.
